# Adeline Le-Bras — Intégration des réflexes archaïques

Site vitrine statique (HTML/CSS/JS, aucune dépendance).

- `index.html` — contenu de la page
- `styles.css` — mise en forme
- `script.js` — menu mobile, animations, formulaire (ouvre la messagerie)

Pour le voir : ouvrir `index.html` dans un navigateur.

À compléter : tarifs, adresse, téléphone, e-mail (aussi dans `script.js` → `CONTACT_EMAIL`), photo et parcours.
